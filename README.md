# Evaluation Projects

## 01 — AI Tutor Evaluation

**Goal:** Evaluate the quality of AI-generated educational responses.

This project develops a structured evaluation framework for AI tutors and learning assistants.

### Evaluation dimensions

| Dimension | What is evaluated |
|---|---|
| Accuracy | Is the information correct? |
| Instruction following | Does the response satisfy the user's request? |
| Pedagogical coherence | Is the explanation appropriate for learning? |
| Cognitive load | Is the information presented in a manageable way? |
| Examples | Are examples relevant and useful? |
| Feedback quality | Does the AI help the learner understand mistakes? |
| Adaptation | Does the response account for the learner's level and context? |

### Method

**Prompt → AI response → Evidence → Rubric → Evaluation → Recommendation**

## 02 — Conversational AI Behavioral Evaluation

**Goal:** Analyze conversational AI behavior across extended interactions.

This project focuses on observable model behavior rather than assuming anything about subjective experience.

### Evaluation areas

- Long-context consistency
- Persona consistency
- Instruction adherence
- Emotional language
- Self-referential statements
- Anthropomorphic patterns
- Relational framing
- Contradictions across turns
- Boundary behavior

### Methodological principle

> Observed conversational behavior does not constitute evidence of subjective consciousness.

The objective is to distinguish **what the model does** from **what the model claims about itself**.
